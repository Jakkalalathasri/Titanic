
 # Titanic Data Analysis

## About the Project
This project focuses on exploring the Titanic passenger dataset to understand passenger characteristics and survival patterns.

## Dataset
The project uses a CSV file containing Titanic passenger data.

## Objective
- Explore passenger information
- Understand survival patterns
- Practice data analysis using a real-world dataset

## Technologies
- Python
- Pandas
